## 文档约定

- **改代码必须同步文档**：`scripts/ci_reconcile.py` 核对测试数 / 前端组件数 / 注册页数与文档一致，漂移即失败；`--update` 可回写期望值。
- **新建文档请按日期或主题命名**，并同步更新本索引。
- **历史方案不要就地改写**：过时内容留在原地作为快照，新事实写进 README 或新建指南，避免读者误判当前实现。
