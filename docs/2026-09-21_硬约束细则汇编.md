## 环境 / 门禁
- Python 固定 `backend/runtimes/cp311/python.exe`；前缀 `/api/v1`；`curl --noproxy '*'`；`X-API-Key: qmt-dev-key`。
- 长任务后台跑（前台 >120s 被 SIGTERM）；「起服务+脚本+停服务」同批后台。Bash 调 PowerShell 被拦 ⇒ 用 PowerShell 工具；`taskkill //F` 被拒 ⇒ `Get-NetTCPConnection` 取 PID。
- ⚠️★ Git Bash **翻译坏绝对路径**（`--outDir`/`curl -o`/**env 变量**）⇒ 用相对路径或 `C:/...`。
- ⚠️★ 行尾判据 = `git ls-files --eol` **加** `git diff --stat`（autocrlf 藏 diff）；**改 CRLF 必须 bytes 级**。
- ⚠️ 单回合删 ≥50 文件被拦 ⇒ `mv`；`rm` 走 trash 护栏，**GB 级目录必失败** ⇒ 报用户。
- ⚠️★ ci_reconcile **必须 cp311**（3.13 无 pytest ⇒ 静默回写 0）且**只收集不执行** ⇒ 另跑 `pytest tests/ -q`；改计数用 bytes 级改常量 + README 两处。
- 门禁 `ci_reconcile.py` + `check_capability_coverage.py`；前端 `npx vitest run && npx tsc --noEmit`。
- 基线（2026-09-21）：后端 **1523 收集 / 1513 passed + 10 skipped**；ci_reconcile 1523/72/43；前端 42 文件 / 401 passed；tsc 0。

## 备份 / 磁盘
- ⚠️★ 备份=**整库全量复制** ⇒ 只限份数封不住磁盘 ⇒ 必须**同时**有 `db_backup_max_total_mb`(4096) + `db_backup_min_keep`(2，地板)。
- ⚠️★ `over_budget=true 且 reclaimable_bytes=0` 是**合法态** ⇒ 界面如实说「受最少 N 份保护、需手工处理」。
- ⚠️★ **跳过 ≠ 失败**（都返 `None`）⇒ 只认 `last_status["action"]`；备份名只到秒 ⇒ 同秒**静默覆盖**。
- ⚠️★★ **采指纹必须在所有写库动作之后**：审计行用 `backup_once(after_create=)`；启动备份必须装在**最后**阶段 `phase_misc`。
- ⚠️★ **「侧车指纹 == 磁盘指纹」在活进程上不可断言**（循环持续写 WAL）⇒ 只断言 db 指纹、`skip xor created`、体积上限、`created→skipped→skipped`。
- ⚠️ 占用能力必须挂 `AppContext.db_backup` + `/config/paths` 的 `db.backups`；1GB+ 复制必须 `asyncio.to_thread`。

## 数据源 / 降级
- ⚠️★ 绝不把「不支持」说成「网络坏了」（真因常是 `_sup_chain()` 刻意返空链）；原因唯一 `last_failure_trace()`，文案唯一 `aggregates.py::_unavailable()`。
- ⚠️★ 券商有 `get_sector_stocks` 但**无 `get_stock_list`** ⇒ 股票池三层降级：本地列表 → 券商板块成分 → 本地日线标的（`codes_with_bars`）。源名 **eltdx**。
- ⚠️★ 名称表 `<数据目录>/stock_names.json`（`eltdx_utils::lookup_name`）；缺失致**三处静默失效**（选股名称列空 / `_is_st()` 恒 False / 涨停池 ST 按 10% 判）。**查不到就留空，绝不用代码冒充**。
- ⚠️★★ **`DataSource`（`base.py`）与 `DataSourceManager`（`registry.py`）无继承关系**：`get_hub()` 返 **manager** ⇒ 给基类加方法路由层调不到且被 `except` 吞掉。判据：**声称在用的源，日志里一次都没出现 ⇒ 代码没跑到**。
- ⚠️★ 公开源有**全局 0.3s 节流锁**（`_PublicSource._MIN_INTERVAL`，跨请求共享）⇒ N 只逐只 = N 次 HTTP + N 次锁等待。批量唯一出口 `DataSourceManager.get_quotes`（code 级降级）；画像走零请求 `derive_detail`。
- ⚠️★★ **`asyncio.gather` + 逐只 `get_quote` 是假的并发**（已踩两次：报价牌 4 只全空 / `overview` 8 指数只剩 2 个）。「一批标的」必须先想批量。
- ⚠️★★ **flaky 不要急着判「测试间污染」**：`test_budget_prunes_oldest` 是真缺陷（`_files()` 按 `st_mtime` 排序 + Windows 同秒 mtime 相同 ⇒ `_plan` 删错，删掉过**最新那份**）。现排序键为**文件名**，碰撞序号补零 `_002`。
- ⚠️★ **Windows 下 `st_mtime` 不可靠**（`copy2` 会带源 mtime）⇒ 「按新旧排序」别用 mtime 当唯一键。
- ⚠️★ **「部分缺失」最容易被静默掉**：`unavailable` 只判「多块全空」则「少了一块」无提示 ⇒ 缺失判据要按块给成因。
- ⚠️★★ **「源都不可用」与「源都在、但都返回空壳」是两种不同的空**：`get_instrument_detail` 在前者抛 `MarketDataUnavailable`（端点有分支接住），在后者走 `return last` 而 last 仍是 `None` —— 端点没接住这一种，`det.get(...)` ⇒ **HTTP 500**。触发条件正是**刚装好的客户端**（没连券商 + 本地没下载过 TDX 数据），正好砸在「基本信息快速查看」上。修法：`if not isinstance(det, dict): note + det = {}`，**仍然走行情补齐**（公开源与本地 TDX 数据无关）。凡兜底/降级分支都要问一句：这个源除了抛异常，会不会**正常地返回 None**？
- ⚠️★ **审计脚本的页面清单必须对齐 `routes.tsx` 的 `menu:false`** ⇒ 否则恒定报「导航失败」。

## 数据 / 同步 / 任务运行时
- ⚠️★ 交易日唯一入口 `core/clock.bar_date()`（非法返 `""` 绝不猜）；「非空」≠「够新」⇒ 同步必须传 `get_kline(min_date=)`。

- ⚠️★ **租约收割器不得杀活着的任务**：`reap_expired` 必须判 `task is not None and not task.done()`；失败必须可感知（`set_failure_hook`）。
- ⚠️★ **`BarLite` 是 `__slots__` 无 `.get`** ⇒ 取时间唯一 `picks.py::bar_time()`。
- ⚠️ 默认调度 16:00 sync_bars → 16:15 classic_screen → 18:30 EOD；**用户改过的 cron/enabled 永不覆盖**；判相位用 `upcoming_fires()`。

## 实测 / 探针
- ⚠️★ 优先级：MCP 真协议 tools/call（看 `isError`）> 全量 GET 遍历 > 界面实测。
- ⚠️★ **REST 错误是带内的**：HTTP 恒 200，真码在 `{"code":...}` ⇒ 遍历**必须解析信封 code**；`/api/openapi.json` 也包在信封里。MCP 在 `/mcp/`（尾斜杠）。
- ⚠️★★ 独立实例：`QMT_DB_PATH` 必须是 **.db 文件路径**且**必须相对**（被 Git Bash 翻转 ⇒ 空库上跑起来还不报错）；用真实库副本（`VACUUM INTO`）；**摆现场必须在服务起来之后**。
- ⚠️★★ **探针断言不可证伪 = 探针错** ⇒ 报 FAIL 前先怀疑探针。
- ⚠️★ 界面探针：限定**目标容器**内；取**最内层** span；用 **Chrome**；不能 `networkidle2`；`CustomEvent("nav")` 已废弃 ⇒ 走菜单栏；console 404 不带 URL ⇒ `page.on("response")`。
- ⚠️★★ **`.wb-body` 在本项目前端根本不存在** ⇒ `xxx || document.body` 会**静默回退到整页**。页内页签找 `[role="tab"]`；工作区页签标题带「×」⇒ 只能前缀匹配。
- ⚠️★ **点行会新开 Tab 并切走** ⇒ 多步探针每步要按标题切回原页签。
- ⚠️★★ **侧栏自选股行是 `<div class="_row_hash">`**，不是 `[role="row"]`/`tr` ⇒ 按表格选择器恒 0。**断言「点行生效」必须看 Tab 数 +1**（`renameTab` 会把没点的用例也判成通过）。
- ⚠️★ **源码扫描断言必须先剥注释再扫**（文档里写明「旧开关 X 已移除」会被判成「X 还在」）。
- ⚠️★ **离线验证列表交互**：puppeteer `setRequestInterception` + `req.respond` 造 `/trade/*` 响应（只拦传输层）。
- ⚠️★ 断言里的**中文证券名不能写死**（真名可能带全角/空格，实测「万  科Ａ」）⇒ 用 `代码|宽松正则`。

## MCP / 架构 / 桌面壳
- ⚠️★ `_EXEC_DENY_DOMAINS` 刻意不暴露 trade/algo/condition/limitup/signal/brokers/api-keys/webhooks/notifications/alerts/scheduler；写入型永不自动暴露。
- ⚠️★ auto_expose 注入参数绝不能进工具签名；判注入用 `hasattr(d,'dependency')`；填参按 `inputSchema` **类型**（`codes` 是 array）。
- ⚠️★ 能力唯一 `DataSource.capabilities`；状态唯一 `core/context.py::AppContext`；`app/routes/` 直写 SQL 无 repository 层；`gateway/`、`engines/` 是**顶层包**。
- ⚠️★ `limitup.py::reset_triggered` 清的是去重集合 ⇒ 重置后已触发标的**会再次触发**（`do_trade=true` 即**重复真实下单**）⇒ 前端必须 `ConfirmModal` 并按 `do_trade` 分支讲后果。
- ⚠️★ 打包 `build_all.sh --nsis` 自己会跑 vite build ⇒ 打包前**不要**先 `npm run build`；打包态 EXE 只认 **QMT_PORT**。
- ⚠️ 无 GPU 必崩 `FATAL: GPU process isn't usable.`（已自愈 `userData/gpu-verdict.json`）；窗口必须立刻建；CSP `script-src 'self'` 拦内联脚本。
- ⚠️★ 子进程 stdio 绝不用 `"ignore"` ⇒ `fs.openSync(log,"a")` 落文件。
- ⚠️★★ **「插件层对了」≠「端点对了」**：`DataSourceManager._plugin_detail()` 有自己的**字段白名单** ⇒ 插件新字段被静默丢弃（端点恒 `null` 而插件单测全绿）。字段清单收敛成一份常量 `datasource/base.py::EXT_DETAIL_KEYS`，并**在 manager 那一层**补测试。
- ⚠️★★ **行情派生字段（市值/PE/PB/换手/振幅/量比/均价/今开/最高/最低）只有公开源（腾讯）有**：本地 TDX 与券商详情**都不提供** ⇒ 打包版会看到一整列 `--`。`/market/stock-info` 取完详情必须**按缺口补一次行情**（`_metric_sources()` 按 `_DETAIL_KEYS` 动态找源，**别写死 tencent**），并返回 `metrics_source` 说明来源。
- ⚠️★ 腾讯快照下标**必须实测**（`_TX_IDX`）：3 个真实样本逐位核对 + 「涨停价 = 昨收 × 比例」自洽验证。哨兵：指数涨跌停 = **-1**、指数市净率 = **0.00** ⇒ 这两字段只认 `> 0`；其余**不许**「<=0 就当没有」。
- ⚠️★ **夹具日期不许写死**：`reconcile_bars(lookback_days=10)` 窗口下界是「今天-10 天」⇒ 写死的日期到期会掉出窗口，测试一夜变红而产品代码没动。一律**相对今天生成**（`BAR_DT`）。
- ⚠️★ **多个工作台 Tab 同时活着时，隐藏 Tab 的 `innerText` 是空串** ⇒ 探针取容器必须筛「可见且有内容」的那个；`new RegExp(字段名)` 遇「市盈(TTM)」要**转义括号**；找面板容器取**最外层**。
