# qmt_work · 项目宣传

> 一份面向交易者、量化爱好者与开发者的**产品宣传文档**。
> 技术细节以仓库根 [`README.md`](../README.md) 与 [`docs/`](README.md) 索引为准。

## 一句话定位

**qmt_work = 多券商量化交易 Agent 平台**：一个进程，同时给你可视化交易终端、REST API、MCP 工具、实时行情推送，还能打包成桌面 App。

## 为什么是 qmt_work

- **真·零 mock**：所有行情、交易、账户数据都来自你本机真实券商客户端。没连券商？明明白白告诉你 503，绝不拿假数据糊弄你。
- **一个后端，四种入口**：Web 界面、REST API、MCP（Cursor / Claude 直连）、WebSocket 推送，想怎么接怎么接。
- **桌面级体验，开箱即用**：打包成单个 `qmt_work.exe`，双击即跑，内置后端、无需另装 Python。
- **多券商统一**：国金 / 华鑫 / 银河 / 中信建投 / 兴业 / 广发等 10 家券商档案；新增券商多数只需加一条配置。
- **量化全家桶**：选股（公式 DSL + 自然语言）、回测、因子、模拟盘、算法交易（TWAP / VWAP）、条件单、涨停监控、目标持仓、风控审计，一应俱全。
- **给 AI 用的交易终端**：通过 MCP，让 Cursor / Claude Desktop 直接查行情、跑回测、下单——把交易能力交给 Agent。

## 适合谁

- **个人量化交易者**：想用一套工具完成看行情、选股、回测、下单。
- **券商 / 机构**：需要可私有化部署、可定制接入的多账户交易终端。
- **开发者 / AI 应用**：通过 REST / MCP 把交易能力接入自己的系统或 Agent。

## 三分钟上手

1. 从 GitHub Releases 下载 `qmt_work-<version>-setup.exe`（或便携 zip）。
2. 安装并启动 `qmt_work.exe`。
3. 在「连接管理」页添加你的券商客户端路径与资金账号。
4. 开始看行情、选股、回测、模拟盘——接好券商即可实盘。

## 能力速览

- **行情**：报价牌 / K 线 / 分时 / 盘口 / 资金流 / ETF / 板块雷达 / 市场结构。
- **研究**：条件选股 / 公式选股 / 因子研究 / 标的检索。
- **交易**：手动 / 算法 / 条件单 / 涨停监控 / 目标持仓 / 多账户网格。
- **账户**：委托持仓成交 / 对账核销 / 模拟盘。
- **自动化**：告警 / Webhook / 外部信号 / 定时任务。
- **系统**：仪表盘 / 连接管理 / 系统状态 / 审计日志 / API Key / 设置。

## 安全与信任

- 零 mock、拒绝假数据；实盘写操作需人工确认。
- 本地优先、数据不出本机；敏感信息脱敏、审计 hash 链。
- Apache 2.0 开源许可。
