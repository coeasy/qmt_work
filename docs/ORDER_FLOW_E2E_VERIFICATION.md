## 发现的问题（均不阻塞下单主流程）

1. **【文案缺陷】Trade 页模式提示与后端实际行为矛盾**：`Trade.tsx` 提示"当前信号模式为「模拟盘」：下表是券商账户的持仓 / 委托 / 成交，**模拟盘的成交不在其中**"，但后端自 2026-10-12 起 `/trade/*` 三个查询端点已按模式分流（paper → 本地 PaperEngine 账本），实测委托页签**明明列着** PAPER 委托。提示会误导用户去别处找单。建议改为如实描述（下表在 paper 模式即模拟盘账本）。
2. **【代码归一化缺口】PaperEngine 不归一化证券代码**：API 直传 `000001` 与 UI 归一化后的 `000001.SZ` 落成**两条持仓**（持仓表可见两行），且裸代码拿不到中文名（名称富化兜底显示代码本身）。UI 路径不受影响（OrderForm 恒发 normCode），但 API/Swagger 直调会产生同一证券的双账。
3. **【环境限制】沙箱内 CDP `Page.captureScreenshot` 挂起**（bringToFront 亦无效），本轮无窗口截图；已用 DOM 级决定性证据（页签行文本）替代。非产品缺陷。
