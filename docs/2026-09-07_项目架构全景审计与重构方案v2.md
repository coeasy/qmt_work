### 5.2 重构项详细说明

#### P0-1: 外部适配器治理 (H1)

**问题**：`adapters/{ths,ptrade,juejin}.py` 继承 `ExternalBrokerAdapter`，所有方法返回"未实现"错误，但 UI `list_broker_profiles` 可见。

**方案**：在 `registry.py` 中为 profile 增加 `status: "planned"` 字段，前端只展示 `status: "active"` 的 profile。planned profile 在「帮助→路线图」中可见。

```python
# registry.py
BrokerProfile(name="同花顺", broker_id="ths", status="planned", ...)
```

#### P0-2: MCP auto_expose 版本守卫 (H2)

**问题**：`auto_expose.py:76` 直接读 `mcp._tool_manager._tools`。

**方案**：加版本检测 + try/except 降级：

```python
def _get_existing_tools(mcp):
    try:
        # FastMCP >= 2.14
        return {t.name for t in mcp._tool_manager._tools.values()}
    except (AttributeError, TypeError):
        try:
            # 尝试公共 API
            import inspect
            if inspect.iscoroutinefunction(mcp.get_tools):
                return set()  # 异步版本，跳过碰撞检测
            return {t.name for t in mcp.get_tools().values()}
        except Exception:
            return set()
```

#### P0-3: 密钥安全 (H3)

**问题**：`data/master.key` 明文 + `webhook_subscriptions.secret` 明文。

**方案**：
1. `master.key` 文件权限设为 `0600`（仅 owner 可读）
2. webhook secret 用 `crypto.py` 的 AES-256-GCM 加密存储
3. 启动时检查文件权限，不合规则告警

#### P0-4: 前端共享 WS hook (H4)

**问题**：`quoteHub.jsx` 和 `useSystemWS.js` 各自实现重连/心跳/退避。

**方案**：抽取 `hooks/useReconnectingSocket.js`：

```javascript
// 通用 WebSocket 重连 hook
export function useReconnectingSocket(url, options) {
  // 共享：指数退避(10次后转30s永不放弃) + 心跳 + onopen/onclose
  // quoteHub 和 useSystemWS 各自调用，传入不同的 onmessage 处理
}
```

#### P0-5: 删除重复 combined_lifespan (M2)

**问题**：`main.py` 179-190 行 `combined_lifespan` 定义两次。

**方案**：删除重复定义。

#### P0-6: 迁移账本收编 (M4)

**问题**：4 张 ad-hoc 表（paper_positions/paper_cash/paper_trades/strategy_market）不在 MIGRATIONS 中。

**方案**：新增 v17 迁移，将 4 张 ad-hoc 表 DDL 正式纳入迁移体系。同时解决 strategy_runs/strategy_logs 双定义（迁移 v10 + tools/strategy_runtime.py）：迁移保留唯一定义，代码中删除 `_ensure_tables`。

#### P1-1: 前端事件总线收敛 (H5)

**问题**：10+ 组件用 `window.dispatchEvent(CustomEvent)` 通信。

**方案**：创建 `lib/eventBus.js` 统一管理：

```javascript
// lib/eventBus.js — 显式事件总线
const handlers = new Map();
export function on(event, fn) { ... }
export function emit(event, data) { ... }
export function off(event, fn) { ... }
```

逐步将 `window.dispatchEvent` 替换为 `eventBus.emit`。

#### P1-2: app/ 解耦 (M1)

**问题**：`app/bootstrap/` 大量 `from gateway import ...` / `from tools import ...`。

**方案**：引入依赖注入——bootstrap phases 接收组件实例而非直接 import：

```python
# phase_engines.py
async def setup(app, *, quote_bus=None, sync_engine=None, ...):
    # 使用传入的实例，而非直接 from gateway.quote_bus import QuoteBus
```

#### P1-3: DB 读写分离锁 (M3)

**问题**：`db.py` 所有读写串行化于 `_lock`。

**方案**：引入 `threading.RLock` + `threading.Semaphore` 读并发：

```python
class DB:
    def __init__(self):
        self._write_lock = threading.Lock()
        self._read_sem = threading.Semaphore(8)  # 8 并发读
    
    def query(self, sql, params=()):
        with self._read_sem:
            # 读操作不阻塞其他读
            ...
    
    def execute(self, sql, params=()):
        with self._write_lock:
            # 写操作独占
            ...
```

#### P1-4: 审计链补 api_key_id (M5)

**问题**：`audit()` 不接收 api_key_id。

**方案**：扩展 `audit()` 签名 + 从 request 注入：

```python
def audit(self, actor, action, target, params, result="ok", ip="", api_key_id=None):
    # api_key_id 从 _common.audit_log 注入
```

#### P1-5: K线复权唯一键 (M6)

**问题**：`kline_cache.put` 用 `INSERT OR REPLACE` 且 `adjust` 非唯一键。

**方案**：修改表结构 + DDL：

```sql
-- v18 迁移
CREATE UNIQUE INDEX IF NOT EXISTS idx_kline_unique 
ON kline_cache(code, period, adjust, dt);
```

#### P1-6: 引擎类归属统一 (M8)

**问题**：引擎类分散在 tools/、paper/、gateway/。

**方案**：创建 `engines/` 统一目录：

```
backend/engines/
  __init__.py
  algo.py        (← tools/algo.py)
  limitup.py     (← tools/limitup.py)
  paper.py       (← paper/paper_engine.py)
  condition_order.py (← tools/condition_order.py)
  strategy_runtime.py (← tools/strategy_runtime.py)
```

保留 `gateway/` 仅基础设施（health/reconcile/wal/quote_bus 等）。
