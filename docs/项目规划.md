# qmt_work 项目规划（Roadmap）

> 本文档是 qmt_work 的**后续规划文档**，描述产品后续演进方向。
> 具体落地以版本发布说明（`docs/release-notes/`）与代码契约为准；本文件不随时间失效，刻意不写交付日期，避免沦为 transient 工作日志。

## 产品定位回顾

qmt_work 是基于 QMT / XTQuant 等多券商客户端的**量化交易 Agent 平台**：同一进程内提供可视化 Web 界面 + MCP + FastAPI REST + WebSocket 实时推送，可打包为独立桌面客户端（EXE）。所有行情 / 交易 / 账户接口均通过真实券商 SDK 调用，**零 mock**。

当前稳定版本：**v0.3.8**。

## 演进原则

- **零 mock 优先**：未连接券商的场景返回 503 + 可操作引导，绝不伪造数据、绝不用空列表冒充。
- **写操作人工确认**：实盘下单、参数变更等高危动作需显式确认，失败不包成 `code=0`。
- **单 PR 可回滚**：每个能力独立、可灰度、可回退。
- **契约驱动**：REST / MCP / WS 接口以 `backend/tests/contracts/*.json` 为基线，CI 门禁（`ci_reconcile.py` / `check_capability_drift.py`）拦截漂移。

## 后续方向

### 一、券商与接入广度

- 推进同花顺量化 / 恒生 PTrade / 掘金量化三家契约券商的 SDK 实接入（当前仅接口契约，待对应 SDK）。
- 新增券商「零代码接入」：完善 `BrokerProfile` 自助注册与适配器模板，降低接入门槛。
- 多账户并行交易与资金调度（当前为统一看板 + 批量下单 / 撤单）。

### 二、策略与量化能力

- **策略市场**：模板化策略的发布、订阅与回测一键复跑。
- **因子库**：离线因子计算 + 因子回测与评价。
- **回测引擎升级**：事件驱动回测、tick 级回放、组合回测。
- **NL 选股增强**：自然语言 → 选股表达式的更强解析与可解释性输出。

### 三、交易与风控

- **组合层目标持仓与再平衡**（当前为单标的差量同步）。
- **风险模型**：组合 VaR / CVaR、行业与个股敞口、实时风控熔断。
- **算法交易扩展**：Iceberg / POV / 智能拆单等更丰富的执行算法。

### 四、体验与部署

- 移动端 / Web 轻量只读客户端。
- 云部署形态（无桌面会话环境下的服务化运行）。
- 一键安装与自动更新体验优化，代码签名默认开启。
- 多语言 SDK（Python / Node / Go）与示例生态建设。

### 五、可观测与合规

- 审计与对账能力下沉为可插拔模块。
- 操作留痕、权限分级、合规报表导出。
