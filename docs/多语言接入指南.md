# qmt_work 多语言接入指南

qmt_work 提供三套对等入口：**REST API**、**MCP（Streamable HTTP）**、**WebSocket**。
本文给出 Python / Node.js / curl 三种语言的调用示例，覆盖鉴权、行情、交易、回测、WS 实时推送。

> 鉴权：所有 `/api/v1/**` 请求需携带密钥，二者任选其一：
> - `Authorization: Bearer <key>`
> - `X-API-Key: <key>`
>
> 主密钥（`QMT_API_KEY`，默认 `qmt-dev-key`）拥有全部权限；
> `/api/v1/api-keys` 可签发多组子密钥（scope 分级 / 限流 / IP 白名单 / 过期 / 轮换）。
> 本机回环（127.0.0.1）请求免鉴权，便于桌面客户端直连。
>
> 统一响应包：`{"code": 0, "message": "ok", "data": {...}}`。
> `code=503` 表示尚未连接券商客户端（不会返回任何模拟数据）。

## 1. Python（requests + websockets）

```python
import json
import asyncio
import requests

BASE = "http://127.0.0.1:21117"
KEY = "qmt-dev-key"
H = {"Authorization": f"Bearer {KEY}"}

# ---- 行情快照 ----
r = requests.get(f"{BASE}/api/v1/market/quote", headers=H, params={"code": "600519.SH"})
print(r.json()["data"])

# ---- 历史 K 线（C1 缓存优先；source 标注 cache/broker/cache_stale）----
r = requests.get(f"{BASE}/api/v1/market/kline", headers=H,
                 params={"code": "600519.SH", "period": "1d", "count": 60})
d = r.json()["data"]
print(f"source={d['source']} bars={len(d['bars'])}")

# ---- 下单（过风控）----
r = requests.post(f"{BASE}/api/v1/trade/order", headers={**H, "Content-Type": "application/json"},
                  json={"code": "600519.SH", "direction": "buy", "price_type": "limit",
                        "price": 1700, "volume": 100, "remark": "py-demo"})
print(r.json())

# ---- 提交条件单（A3 跨日续作：valid_days=3）----
r = requests.post(f"{BASE}/api/v1/trade/conditions",
                  headers={**H, "Content-Type": "application/json"},
                  json={"code": "600519.SH", "side": "buy", "trigger_type": "gte",
                        "trigger_price": 1750, "volume": 100, "valid_days": 3})
print(r.json()["data"])  # {"id": "...", "status": "pending", "expire_at": "..."}

# ---- 回测 ----
r = requests.post(f"{BASE}/api/v1/backtest", headers={**H, "Content-Type": "application/json"},
                  json={"symbol": "600519.SH", "strategy": "ma_cross",
                        "count": 250, "initial_capital": 100000})
print(r.json()["data"]["metrics"])

# ---- 注册出站 webhook（B2：接收事件投递）----
r = requests.post(f"{BASE}/api/v1/webhooks",
                  headers={**H, "Content-Type": "application/json"},
                  json={"name": "my-risk-system", "url": "https://my.server/qmt-events",
                        "events": "order.* deal.* risk.*", "secret": "shared-secret"})
print(r.json())

# ---- WebSocket 实时推送 ----
async def ws_demo():
    import websockets
    uri = f"ws://127.0.0.1:21117/ws?token={KEY}"
    async with websockets.connect(uri) as ws:
        # 订阅行情
        await ws.send(json.dumps({"type": "subscribe", "codes": ["600519.SH", "000001.SZ"]}))
        while True:
            msg = json.loads(await ws.recv())
            t = msg.get("type")
            if t == "quotes":
                for q in msg["data"]:
                    print(f"[quote] {q['code']} last={q.get('last')}")
            elif t in ("order_event", "deal_event", "risk_circuit", "condition_triggered"):
                print(f"[{t}] {msg['data']}")

asyncio.run(ws_demo())
```

### 验证出站 webhook 签名（Python 服务端）

```python
import hmac, hashlib

def verify(secret: str, body: bytes, sig_header: str) -> bool:
    # sig_header = "t=1695000000,v1=xxxx"
    parts = dict(p.split("=", 1) for p in sig_header.split(","))
    ts, v1 = parts.get("t", ""), parts.get("v1", "")
    mac = hmac.new(secret.encode(), f"{ts}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(mac, v1)
```

## 2. Node.js（axios + ws）

```js
const axios = require("axios");
const WebSocket = require("ws");

const BASE = "http://127.0.0.1:21117";
const KEY = "qmt-dev-key";
const api = axios.create({ baseURL: BASE, headers: { Authorization: `Bearer ${KEY}` } });

(async () => {
  // 行情
  const q = await api.get("/api/v1/market/quote", { params: { code: "600519.SH" } });
  console.log("quote:", q.data.data);

  // K 线（缓存优先）
  const k = await api.get("/api/v1/market/kline",
    { params: { code: "600519.SH", period: "1d", count: 30 } });
  console.log(`kline source=${k.data.data.source} bars=${k.data.data.bars.length}`);

  // 下单
  const o = await api.post("/api/v1/trade/order", {
    code: "600519.SH", direction: "buy", price_type: "limit",
    price: 1700, volume: 100, remark: "node-demo"
  });
  console.log("order:", o.data);

  // 条件单（跨日续作）
  const c = await api.post("/api/v1/trade/conditions", {
    code: "600519.SH", side: "buy", trigger_type: "gte",
    trigger_price: 1750, volume: 100, valid_days: 3
  });
  console.log("condition:", c.data.data);

  // 回测
  const bt = await api.post("/api/v1/backtest", {
    symbol: "600519.SH", strategy: "ma_cross", count: 250, initial_capital: 100000
  });
  console.log("backtest metrics:", bt.data.data.metrics);
})();

// WebSocket 实时推送
const ws = new WebSocket(`ws://127.0.0.1:21117/ws?token=${KEY}`);
ws.on("open", () => ws.send(JSON.stringify({ type: "subscribe", codes: ["600519.SH"] })));
ws.on("message", (raw) => {
  const msg = JSON.parse(raw);
  if (msg.type === "quotes") console.log("[quote]", msg.data);
  else console.log(`[${msg.type}]`, msg.data);
});
```

## 3. curl

```bash
KEY="qmt-dev-key"

# 行情快照
curl -s "http://127.0.0.1:21117/api/v1/market/quote?code=600519.SH" \
  -H "Authorization: Bearer $KEY" | python -m json.tool

# 历史 K 线（缓存优先）
curl -s "http://127.0.0.1:21117/api/v1/market/kline?code=600519.SH&period=1d&count=30" \
  -H "Authorization: Bearer $KEY" | python -m json.tool

# 下单
curl -s -X POST "http://127.0.0.1:21117/api/v1/trade/order" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"code":"600519.SH","direction":"buy","price_type":"limit","price":1700,"volume":100}' \
  | python -m json.tool

# 查询持仓
curl -s "http://127.0.0.1:21117/api/v1/account/positions" \
  -H "Authorization: Bearer $KEY" | python -m json.tool

# 风控配置（含日级限额与熔断状态 B4）
curl -s "http://127.0.0.1:21117/api/v1/config/risk" -H "Authorization: Bearer $KEY" | python -m json.tool

# 设置日亏损熔断阈值
curl -s -X PUT "http://127.0.0.1:21117/api/v1/config/risk" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"daily_loss_limit": 50000}' | python -m json.tool

# 触发一键熔断（停止买入开仓）
curl -s -X POST "http://127.0.0.1:21117/api/v1/config/risk/circuit" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"trip","reason":"手动停盘"}' | python -m json.tool

# 审计 hash 链完整性校验（D4 防篡改）
curl -s "http://127.0.0.1:21117/api/v1/audit/verify?limit=200000" \
  -H "Authorization: Bearer $KEY" | python -m json.tool

# 提交回测
curl -s -X POST "http://127.0.0.1:21117/api/v1/backtest" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"symbol":"600519.SH","strategy":"ma_cross","count":250}' | python -m json.tool

# 注册出站 webhook
curl -s -X POST "http://127.0.0.1:21117/api/v1/webhooks" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"name":"my-system","url":"https://my.server/qmt","events":"order.* deal.*","secret":"s3cr3t"}' \
  | python -m json.tool

# 运行时配置中心（引擎参数热更新，无需重启）
curl -s "http://127.0.0.1:21117/api/v1/config/runtime" \
  -H "Authorization: Bearer $KEY" | python -m json.tool

# 热更新：行情微批窗口改为 200ms
curl -s -X PUT "http://127.0.0.1:21117/api/v1/config/runtime" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"sync.batch_window": 0.2}' | python -m json.tool

# 恢复默认（单 key 或全部）
curl -s -X POST "http://127.0.0.1:21117/api/v1/config/runtime/reset" \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"key":"sync.batch_window"}' | python -m json.tool
```

> 运行时配置项一览（`GET /api/v1/config/runtime` 实时返回生效值/默认值/说明）：
>
> | key | 默认 | 说明 |
> |-----|------|------|
> | `sync.batch_window` | 0.1s | 行情微批聚合窗口（帧数/延迟权衡） |
> | `sync.snapshot_interval` | 5s | 账户快照归档间隔 |
> | `sync.recent_window` | 30s | WS 断线补发窗口 |
> | `condition.interval` | 2s | 条件单轮询间隔 |
> | `health.check_interval` | 5s | 连接健康检查间隔 |
> | `reconcile.interval` | 300s | 委托对账巡检间隔 |
> | `algo.poll_interval` | 1s | 算法单拆单轮询间隔 |
> | `limitup.poll_interval` | 0.5s | 涨停监控轮询间隔 |
>
> 修改立即生效（引擎在每轮循环读取最新值），持久化于 `runtime_config` 表，重启不丢失。

## 4. MCP 接入（Claude / Cursor 等 MCP 客户端）

MCP 端点：`POST http://127.0.0.1:21117/mcp`（Streamable HTTP）。
在 MCP 客户端配置中添加：

```json
{
  "mcpServers": {
    "qmt_work": {
      "url": "http://127.0.0.1:21117/mcp",
      "headers": { "Authorization": "Bearer qmt-dev-key" }
    }
  }
}
```

接入后即可在对话中直接调用 qmt_work 的全部工具：`get_quote` / `get_kline` / `place_order` /
`condition_submit` / `run_backtest` / `condition_cancel` / `twap` / `iceberg` / …。

## 4.1 打包 EXE：同目录配置文件与数据

PyInstaller 打包的 `qmt_work.exe` 支持**零配置开箱即用**：

- **首次启动自动生成** `qmt_work_config.json`（与 exe 同目录），含全部可配项 + 中文说明；
- **数据库 / 日志默认落 exe 同目录**：`data/app.db`（含 WAL）与 `logs/`，程序更新不丢数据；
- 配置优先级：**环境变量(`QMT_*`) > `qmt_work_config.json` > `.env` > 默认值**；
  - `db_path` / `log_dir` 填相对路径时以 exe 同目录为基准，也可填绝对路径；
- 桌面壳（Electron）通过 `QMT_DB_PATH` / `QMT_PORT_FILE` 环境变量覆盖，行为不变。

```jsonc
// qmt_work_config.json（示例：修改端口与数据库位置后重启生效）
{
  "port": 9000,
  "db_path": "D:/qmt-data/app.db",
  "log_dir": "D:/qmt-logs"
}
```

## 5. 事件类型速查（WebSocket / 出站 webhook）

| 事件                | 说明                          |
|---------------------|-------------------------------|
| `quotes`            | 行情微批帧（100ms 聚合）       |
| `order.event`       | 委托新增 / 状态变化            |
| `deal.event`        | 新成交                         |
| `account`           | 账户快照（净值/持仓/资金）     |
| `risk.circuit`      | 风控熔断触发/解除（B4）        |
| `condition.*`       | 条件单创建/触发/到期（A3）     |
| `algo.*`            | 算法单进度/完成                |
| `limitup.*`         | 涨停触发/打板下单              |
| `reconcile`         | 委托对账核销结果（A2）         |
| `broker.*`          | 连接健康/重连状态              |
