# qmt_work API & MCP 接入指南

qmt_work 是面向量化交易的多券商统一平台，提供 **REST API**、**MCP（Streamable HTTP）**、**WebSocket** 三套对等入口。本文给出 Python / Node.js / curl 三种语言的完整调用示例，覆盖鉴权、行情、交易、回测、风控、可观测性等全部能力。

> **基地址**：`http://<host>:<port>`（默认 8000，端口被占时自动 +1；打包 EXE 首次启动自动扫描可用端口）
>
> **鉴权**：所有 `/api/v1/**` 请求需携带密钥，二者任选其一：
> - `Authorization: Bearer <key>`
> - `X-API-Key: <key>`
>
> 主密钥（`QMT_API_KEY`，默认 `qmt-dev-key`）拥有全部权限；`/api/v1/api-keys` 可签发多组子密钥（scope 分级 / 限流 / IP 白名单 / 过期 / 轮换）。本机回环（127.0.0.1）请求免鉴权，便于桌面客户端直连。
>
> **统一响应包**：`{"code": 0, "message": "ok", "data": {...}}`。
> `code=503` 表示尚未连接券商客户端（不会返回任何模拟数据）；`code=400` 表示请求参数错误；`code=401` 表示鉴权失败（无/错密钥）；`code=403` 表示密钥 scope 不足；`code=429` 表示触发限流。

### 远程调用与鉴权（第三方服务场景）

服务监听 `0.0.0.0`（默认），**局域网 / 远程服务器上的第三方服务可直接调用**：

| 场景 | 行为 |
|------|------|
| 本机浏览器 / 桌面壳 | 回环免鉴权，无需 Key |
| 远程 API / MCP / WS | 必须携带 Key（`Authorization: Bearer` 或 `X-API-Key`） |
| 远程浏览器打开 Web UI | **免鉴权**（前端静态页 / API 文档为公共路径），API 调用需在「设置 → 远程访问 API Key」填写 Key 后自动附带 |
| 监控探针（health/ready） | 公共路径，免鉴权 |
| `/mcp/`（MCP 端点） | 需 Key，无 Key 返回 401 |

**scope 分级**（签发子密钥时指定，逗号分隔）：

| scope | 覆盖端点 | 用途 |
|-------|---------|------|
| `market` | `/market/*` `/reference/*` `/factors` `/sync` | 只读行情/参考数据 |
| `trade` | `/trade/*` `/algo/*` `/limitup/*` `/signal/*` `/paper/*` `/target-portfolio/*` `/rebalance` | 交易执行 |
| `account` | `/account/*` | 账户与资产 |
| `backtest` | `/backtest/*` `/strategies/*` `/strategy-market/*` | 回测与策略 |
| `admin` | `/config/*` `/api-keys` `/brokers` `/scheduler` `/webhooks` `/alerts` `/notifications` `/reconcile` `/wal` `/observability` `/metrics` `/agent` `/audit` | 管理/运维 |
| `*` | 全部 | 通配 |

> **安全提示**：`/scheduler/shutdown`、`/scheduler/restart`、`/trade/order`、`/signal/submit` 等敏感端点需要 `admin` / `trade` scope——给第三方签发的 Key 请按最小权限原则设置 scope 与 `rate_limit`。

**CORS**：第三方**服务端**（Python/Node/curl）调用不受 CORS 限制；若需**浏览器页面**跨域直调 API，在服务端配置 `QMT_CORS_ORIGINS=http://your-site.com`（逗号分隔，空 = 不启用跨域）。

```python
r = requests.get(f"{BASE}/api/v1/backtest/jobs/{job_id}", headers=H)

# ---- 模拟盘下单 ----
r = requests.post(f"{BASE}/api/v1/paper/order",
                  headers={**H, "Content-Type": "application/json"},
                  json={"code": "SH600000", "side": "buy", "price": 12.0, "volume": 100})

                  headers={**H, "Content-Type": "application/json"},

                        "events": "order.* deal.* risk.*", "secret": "shared-secret"})
print(r.json())

# ---- 运行时配置热更新 ----
r = requests.put(f"{BASE}/api/v1/config/runtime",
                 headers={**H, "Content-Type": "application/json"},
                 json={"sync.batch_window": 0.2})  # 行情微批窗口改为 200ms
print("热更新:", r.json())

# ---- 风控熔断 ----
r = requests.post(f"{BASE}/api/v1/config/risk/circuit",
                  headers={**H, "Content-Type": "application/json"},
                  json={"action": "trip", "reason": "手动停盘"})
print("熔断:", r.json())

# ---- 审计完整性校验 ----
r = requests.get(f"{BASE}/api/v1/audit/verify", headers=H, params={"limit": 100000})
print("审计链完整:", r.json()["data"]["ok"])

# ---- WebSocket 实时推送 ----
async def ws_demo():
    import websockets
    uri = f"ws://127.0.0.1:8000/api/v1/ws?token={KEY}"
    async with websockets.connect(uri) as ws:
        await ws.send(json.dumps({"type": "subscribe", "codes": ["SH600000", "SZ000001"]}))
        for _ in range(10):
            msg = json.loads(await ws.recv())
            if msg.get("type") == "quotes":
                for q in msg["data"]:
                    print(f"[quote] {q.get('code')} last={q.get('last')}")
            else:
                print(f"[{msg['type']}]", msg.get("data"))

asyncio.run(ws_demo())
```

### 验证出站 webhook 签名

qmt_work 对出站 webhook 使用 HMAC-SHA256 签名：

```
X-SmartQMT-Signature: t=<unix_ts>,v1=<hmac_hex>
```

```python
def verify_webhook(secret: str, body: bytes, sig_header: str) -> bool:
    """验证 qmt_work 出站 webhook 签名"""
    parts = dict(p.split("=", 1) for p in sig_header.split(","))
    ts, v1 = parts.get("t", ""), parts.get("v1", "")
    mac = hmac.new(secret.encode(), f"{ts}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(mac, v1)
```

### 验证入站信号签名（外部系统 → qmt_work）

qmt_work 的 `/signal/webhook` 入站端点也支持 HMAC-SHA256 签名校验（`QMT_WEBHOOK_SECRET` 非空时强制）：

```python
secret = "your-webhook-secret"
body = json.dumps({"code": "SH600000", "side": "buy", "volume": 100}).encode()
sig = hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()

requests.post(f"{BASE}/api/v1/signal/webhook",
              headers={"Content-Type": "application/json", "x-signature": sig},
              data=body)
```

## 2. Node.js 完整示例

```js
const axios = require("axios");
const WebSocket = require("ws");
const crypto = require("crypto");

const BASE = "http://127.0.0.1:8000";
const KEY = "qmt-dev-key";
const api = axios.create({ baseURL: BASE, headers: { Authorization: `Bearer ${KEY}` } });

(async () => {
  // 健康检查
  const h = await api.get("/api/v1/health");
  console.log("版本:", h.data.data.version, "| 状态:", h.data.data.status);

  // 行情快照
  const q = await api.get("/api/v1/market/quote", { params: { code: "SH600000" } });
  if (q.data.code === 0) console.log("最新价:", q.data.data.lastPrice);

  // K 线（缓存优先）
  const k = await api.get("/api/v1/market/kline",
    { params: { code: "SH600000", period: "1d", count: 30 } });
  console.log(`K线 来源=${k.data.data.source} 条数=${k.data.data.count}`);

  // 下单
  const o = await api.post("/api/v1/trade/order", {
    code: "SH600000", side: "buy", price_type: "limit",
    price: 12.5, volume: 100, remark: "node-demo"
  });
  console.log("委托:", o.data);

  // 条件单（跨日续作）
  const c = await api.post("/api/v1/trade/conditions", {
    code: "SH600000", side: "buy", trigger_type: "gte",
    trigger_price: 13.0, volume: 100, valid_days: 3
  });
  console.log("条件单:", c.data.data);

  // 提交回测
  const bt = await api.post("/api/v1/backtest/jobs", {
    broker_id: "base", code: "SH600000", period: "1d",
    start: "2024-01-01", end: "2024-06-30",
    strategy: "ma_cross", params: { fast: 5, slow: 20 }, capital: 100000
  });
  const jobId = bt.data.data.id;
  console.log("回测任务:", jobId);

  // 查询回测结果
  const btResult = await api.get(`/api/v1/backtest/jobs/${jobId}`);
  console.log("回测结果:", JSON.stringify(btResult.data.data, null, 2));

  // 模拟盘
  const paper = await api.post("/api/v1/paper/order", {
    code: "SH600000", side: "buy", price: 12.0, volume: 100
  });
  console.log("模拟盘:", paper.data);

  // 生成策略
  const strat = await api.post("/api/v1/strategies/generate", {
    strategy: "ma_cross", params: { fast: 5, slow: 20 }
  });
  console.log("策略代码长度:", strat.data.data.code.length);

  // 目标持仓同步（dry-run）
  const tp = await api.post("/api/v1/target-portfolio/sync", {
    targets: { "SH600000": 0.3, "SZ000001": 0.2 }, dry_run: true
  });
  console.log("调仓方案:", tp.data);

  // 注册 webhook
  const wh = await api.post("/api/v1/webhooks", {
    name: "my-system", url: "https://my.server/qmt",
    events: "order.* deal.*", secret: "s3cr3t"
  });
  console.log("Webhook ID:", wh.data.data.id);

  // 运行时配置热更新
  const cfg = await api.put("/api/v1/config/runtime", { "sync.batch_window": 0.2 });
  console.log("热更新:", cfg.data);

  // 审计链校验
  const audit = await api.get("/api/v1/audit/verify", { params: { limit: 100000 } });
  console.log("审计链完整:", audit.data.data.ok);

  // 风控熔断
  const circuit = await api.post("/api/v1/config/risk/circuit", {
    action: "trip", reason: "手动停盘"
  });
  console.log("熔断:", circuit.data);

  // 可观测性指标
  const obs = await api.get("/api/v1/observability/metrics-summary");
  console.log("运行指标:", obs.data.data);

})();

// WebSocket 实时推送
const ws = new WebSocket(`ws://127.0.0.1:8000/api/v1/ws?token=${KEY}`);
ws.on("open", () => ws.send(JSON.stringify({ type: "subscribe", codes: ["SH600000"] })));
ws.on("message", (raw) => {
  const msg = JSON.parse(raw);
  if (msg.type === "quotes") console.log("[quote]", msg.data);
  else console.log(`[${msg.type}]`, msg.data);
});

// 验证 qmt_work 出站 webhook 签名
function verifyQMTWebhook(secret, body, sigHeader) {
  const parts = {};
  for (const p of sigHeader.split(",")) {
    const [k, v] = p.split("=", 2);
    parts[k] = v;
  }
  const mac = crypto
    .createHmac("sha256", secret)
    .update(`${parts.t}.` + body)
    .digest("hex");
  return crypto.timingSafeEqual(Buffer.from(mac), Buffer.from(parts.v1));
}

// 发送签名信号到 qmt_work 入站端点
function sendSignedSignal(secret, signal) {
  const body = JSON.stringify(signal);
  const sig = crypto.createHmac("sha256", secret).update(body).digest("hex");
  return axios.post(`${BASE}/api/v1/signal/webhook`, signal, {
    headers: { "Content-Type": "application/json", "x-signature": sig }
  });
}
```

## 4. MCP 接入（Claude / Cursor 等 MCP 客户端）

MCP 端点：`POST http://127.0.0.1:8000/mcp/`（Streamable HTTP，协议版本 2024-11-05）。

MCP 使用 SSE 流式响应，请求头必须包含：
```
Accept: application/json, text/event-stream
```

> **会话管理**：Streamable HTTP 为有状态协议——首个请求 `initialize` 后，响应头会返回 `Mcp-Session-Id`，**后续 `tools/list` / `tools/call` 请求必须携带该头**（`Mcp-Session-Id: <id>`）。主流 MCP 客户端（Claude Desktop / Cursor / VS Code）自动处理；手动 curl 调试需自行提取。

在 Claude Desktop / Cursor 的 MCP 配置中添加：

```json
{
  "mcpServers": {
    "qmt_work": {
      "url": "http://127.0.0.1:8000/mcp/",
      "headers": {
        "Authorization": "Bearer qmt-dev-key",
        "Accept": "application/json, text/event-stream"
      }
    }
  }
}
```

> **远程部署时**：`url` 换成 `http://<服务器IP>:<端口>/mcp/`，`Authorization` 换成已签发 Key（MCP 请求同样受 scope 校验）。

接入后即可在对话中直接调用 qmt_work 的全部 MCP 工具：

| 类别 | 工具 |
|------|------|
| 行情 | `get_quote` / `get_full_tick` / `get_kline` / `get_tick` / `get_stock_list` / `search_stocks` / `l2_transactions` |
| 交易 | `place_order` / `cancel_order` / `cancel_order_price` / `query_position` / `query_cash` / `query_orders` / `query_deals` |
| 账户 | `monitor_account` / `account_status` |
| 再平衡 | `generate_rebalance` |
| 条件单 | `condition_submit` / `condition_cancel` / `condition_list` |
| 算法单 | `algo_submit` / `algo_pause` / `algo_resume` / `algo_cancel` / `algo_list` |
| 涨停 | `limitup_pool_add` / `limitup_pool_remove` / `limitup_start` / `limitup_stop` / `limitup_status` |
| 回测 | `run_backtest` / `compare_backtests` / `sensitivity_analysis` |
| 绩效 | `analyze_slippage` / `analyze_contribution` / `monthly_pnl` / `net_value_series` |
| 参考 | `trading_calendar` / `sector_list` / `sector_stocks` / `financial_summary` |
| 策略 | `generate_strategy` / `save_qmt_strategy` |
| 持仓 | `target_portfolio_sync` |
| 券商 | `list_brokers` / `list_broker_profiles` / `broker_status` |

> 交易类操作（`place_order` / `cancel_order` / `generate_rebalance` / `algo_submit` / `order_target_position` / `condition_submit` / `limitup_start` 自动买入）必须先与用户确认方向、数量、价格后再执行。

### 手动测试 MCP（curl，含会话管理）

```bash
MCP="http://127.0.0.1:8000/mcp/"
AUTH="Authorization: Bearer qmt-dev-key"
CT='Content-Type: application/json'
ACCEPT='Accept: application/json, text/event-stream'

# 1. initialize 握手（响应头含 Mcp-Session-Id）
curl -s -i -X POST "$MCP" -H "$CT" -H "$ACCEPT" -H "$AUTH" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"1.0"}}}'

# 2. 提取 Session ID（Linux/macOS）
SID=$(curl -s -i -X POST "$MCP" -H "$CT" -H "$ACCEPT" -H "$AUTH" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"1.0"}}}' \
  | grep -i '^mcp-session-id:' | tr -d '\r' | awk '{print $2}')

# 3. 列出工具（携带 Session ID）
curl -s -X POST "$MCP" -H "$CT" -H "$ACCEPT" -H "$AUTH" -H "Mcp-Session-Id: $SID" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}'

# 4. 调用工具（查询券商列表）
curl -s -X POST "$MCP" -H "$CT" -H "$ACCEPT" -H "$AUTH" -H "Mcp-Session-Id: $SID" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"list_brokers","arguments":{}}}'
```

> **注意**：MCP 响应为 SSE 格式（`event: message\ndata: {...}`）。`curl` 输出需自行解析 `data:` 行。Claude / Cursor 等 MCP 客户端会自动处理 SSE 与 Session ID。

## 5. WebSocket 实时推送

端点：`ws://127.0.0.1:8000/api/v1/ws?token=<key>`（本机回环免 token）。

连接后发送 JSON 消息订阅：

```json
{"type": "subscribe", "codes": ["SH600000", "SZ000001"]}
```

服务端推送事件类型：

| 事件 | 说明 |
|------|------|
| `quotes` | 行情微批帧（默认 100ms 聚合） |
| `order_event` | 委托新增 / 状态变化 |
| `deal_event` | 新成交 |
| `account` | 账户快照（净值/持仓/资金） |
| `risk_circuit` | 风控熔断触发/解除 |
| `condition.*` | 条件单创建/触发/到期 |
| `algo.*` | 算法单进度/完成 |
| `limitup.*` | 涨停触发/打板下单 |
| `reconcile` | 委托对账核销结果 |
| `broker.*` | 连接健康/重连状态 |

断线重连后自动补发最近 30 秒事件窗口（`sync.recent_window` 可配置）。

## 6. 打包部署

```bash
# 一键构建（前端 + 后端 EXE + Electron 桌面壳）
./build_all.sh

# 构建 NSIS 一键安装包（Setup.exe）
./build_all.sh --dist

# 仅构建后端
./build_all.sh --backend-only
```

**两种交付形态**：

| 形态 | 命令 | 产物 | 适用 |
|------|------|------|------|
| 便携解压版 | `./build_all.sh` | `qmt_work-0.1.0.zip`（解压即用） | 绿色运行，无需安装 |
| 一键安装版 | `./build_all.sh --dist` | `qmt_work-Setup-0.1.0.exe`（NSIS 安装向导） | 双击安装，桌面快捷方式 + 开机自启开关 |

**运行后**：

- 首次启动自动生成 `qmt_work_config.json`（与 exe 同目录），含全部可配项 + 中文说明
- 数据库 / 日志默认落 exe 同目录：`data/app.db`（含 WAL）与 `logs/`，程序更新不丢数据
- 配置优先级：**环境变量(`QMT_*`) > `qmt_work_config.json` > `.env` > 默认值**
- 端口被占用时自动 +1，最多重试 10 次
- 桌面壳（Electron）自动拉起后端并发现端口（`QMT_PORT_FILE`）；可在设置页开启开机自启

> **局域网/远程访问**：确保配置文件 `host: "0.0.0.0"`（默认），放行防火墙端口；第三方按上文鉴权方式携带 Key 调用。

```jsonc
// qmt_work_config.json

  "port": 9000,

  "log_dir": "D:/qmt-logs",
```
