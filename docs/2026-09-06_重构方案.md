## 一、项目梳理

### 1.1 主要功能

多券商量化平台（Windows 优先），基于 QMT/XTQuant，FastAPI 单进程同源托管 REST(199 端点)+WS+MCP+SPA，可打包 Electron 桌面 EXE：

- **行情面**：标的检索（代码/名称/拼音/板块）、实时快照、历史 K 线（多周期+复权）、分时、
  板块榜/成分/轮动矩阵、ETF 清单、资金流（个股/板块/落库回放）、市场概览、涨停扫描；
  数据面三级回退 **券商 SDK → eltdx(TDX 公共行情) → 本地数据仓**，全空 503（零 mock 铁律）。
- **交易面**：多券商多账户连接（含多版本 ABI 桥接子进程）、下单/撤单/持仓/委托、
  算法单（TWAP/VWAP）、条件单、网格、目标持仓差量同步、对账核销、风控/限流/审计 hash 链。
- **策略与研究**：回测（向量化+参数扫描+任务队列）、因子研究、指标 DSL、选股引擎、
  自然语言选股、策略市场/策略运行容器、模拟盘。
- **平台面**：能力自描述（REST→MCP tool 自动暴露）、运行时配置热更新、任务运行时、
  告警引擎+四通道通知（钉钉/企微/飞书/邮件）、出站 Webhook（HMAC+退避）。

  app/datasource/          数据面抽象：registry(DataSourceManager)/eltdx/local_store/board/pinyin
  app/indicators|screener|analysis|sync/  指标·选股·分析·K线同步

## 二、重构原则

1. **行为零变更**：信封格式、错误码、文案、TTL/并发参数不变；前端契约不受影响。
2. **小步快跑**：每个模块完成后跑 pytest 回归（基线：570 passed；14 个环境性失败——
   12 个联机契约测试需本地 21118 存活 + 2 个宿主解释器恰为 cp311 的 ABI 选择差异，与代码无关）。
3. **分层归位**：路由层只做 参数校验 → 调服务 → 包信封；业务逻辑进 app/services/。
