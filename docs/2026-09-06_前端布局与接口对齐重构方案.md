# qmt_work 前端布局与前后端接口对齐重构方案（2026-09-06）

> 状态：**第一期（高危修复）已完成**。本文档基于一轮 very thorough 的前端界面 + 接口对齐审计。

## 一、审计总结论

- **接口对齐面很干净**：api.js 约 150 个封装方法 × 后端 199 端点逐条比对——前端调用不存在路径 0、
  HTTP 方法不匹配 0、高频页面响应字段错位 0（MarketTools/TargetPortfolio 等新面板亦核对一致）。
  问题集中在**参数语义与前端内部实现**（见下）。
- **布局骨架成熟**（Tab=工作区+分屏树+keep-alive+后台停表），但有 1 个真 CSS bug 和若干窄窗/空态缺口。
- **最严重发现（已修复）**：TargetPortfolio 模拟运行复选框 `e.checked` 写法错误，
  用户取消勾选后 `dry_run` 变 undefined → 后端默认 False → **以为是预演、实际真实下单**。

## 七、扩展优化（2026-09-06，✅ 部分完成）

1. **WS 重连语义统一（✅）**：useSystemWS 此前 10 次重试后永久置 offline（等待组件重挂载），
   与 quoteHub 的「10 次指数退避后 30s 慢速重连、永不放弃」两套语义并存——后端短暂宕机
   超过 10 次窗口后系统状态条会永久显示离线。现统一为：前 10 次指数退避（0.5s→15s 封顶）
   → 30s 固定间隔慢速重连永不放弃。
2. **toast 多消息纵向堆叠（✅）**：.toast 改 flex + 相邻间距，不再同位叠写。
3. **窄窗自适应（✅）**：.grid-2/3/4 改 auto-fit + minmax，窄窗不再挤压溢出。
4. **BottomDock 遮挡（✅）**：.bd-list 加 min-height 兜底，展开态不再被压没。
5. **className 差集 CI 门禁（✅）**：新增 vitest 门禁测试扫描全部 JSX 静态类名 vs
   styles.css（白名单=动态模板串/语义标记），并补齐 .modal-mask/.modal/.otm-* 等此前
   使用未定义的弹窗底座样式——「改 JSX 忘写样式」从此被测试拦住。
6. **正文 i18n（~200 处硬编码中文）**：唯一遗留，工程量大、需产品层面确认英文文案，
   已单独记录不在代码改造范围。
- 验收：lint 零警告 / build ✅ / vitest **111 用例全过**（+1 差集门禁）。
