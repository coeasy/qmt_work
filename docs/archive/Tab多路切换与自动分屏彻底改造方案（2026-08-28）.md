# Tab 多路切换与自动分屏彻底改造方案（2026-08-28）

> 结论先行：**「新开浏览器问题依然存在」证明这不是 localStorage 持久化污染，而是运行时导航模型的缺陷。**
> 当前 Workbench 的 tab 是「页面类型」而不是「页面实例」，切 tab 靠卸载重挂，换股票靠 sessionStorage 全局变量。
> 这三个模型级缺陷叠加，打再多兜底补丁都无法根治。本方案整体替换为：**实例级 Tab + keep-alive 多路切换 + QuoteHub 单连接多路复用 + tab 内分屏 + 自动分屏**，
> 对标通达信 / 东方财富终端的多窗口行为。

---

## 1. 问题根因定位（代码证据）

审查链路：`App.jsx → Workbench.jsx → Pane.jsx → pagesRegistry.jsx → MarketData.jsx → useMarket.js / useHotkeys.js / lib/trade.js`。

| # | 根因 | 代码证据 | 用户可感知症状 |
|---|------|----------|----------------|
| R1 | **导航是类型级，不是实例级**：`nav` 事件只带 `pageKey` 字符串，同一页面全局只能存在一个 tab | `Workbench.openPage()`：`tabs.includes(key) ? 不新增 : 新增`；`MarketData` 的 `code` 只在 `useState(() => sessionStorage.getItem(...))` 挂载时读一次 | 已打开行情 tab 时按 F3/F4、从涨停监控点股票、任何"带代码跳转"都**点了没反应**——tab 激活了但 `code` 不变 |
| R2 | **切 tab = 整树卸载重挂**：`<ErrorBoundary key={activeRootId}>` key 变化导致 Pane 及整棵页面树 remount | Workbench L172：`key={activeRootId}`；MarketData 所有 state（code/period/adj/指标/WS）都是组件内部 state | 切走再切回：WS 断开重连、K 线重拉、周期/复权/指标选择全部丢失 |
| R3 | **每 tab 一条独立 WebSocket + 各自退避重连**：N 个行情页 = N 条连接，切走即断连 | MarketData `connect()/scheduleReconnect()` 自建 WS | 频繁切换时连接风暴；服务端订阅压力线性放大 |
| R4 | **三层持久化交叉 + 双 state 树**：`workbench.v1`（tabs+active）、`.roots`（rootMap）、`panes.v2`（每 root 布局树）各自读写，且 Workbench 同时维护两颗 state | closeTab 里 8 行原子提交注释；Pane 里 `sanitize/ensureHasLeaf` 双重兜底；代码注释自证历史 bug（nextId 冲突、旧 wb1/wb2、race condition） | 任何一环 race/损坏即空白，历史上反复修补；唯一 tab 的「×」按钮实际是 no-op（`rootIdFor` 恒等，"重置"不生效） |
| R5 | **右侧固定栏挤压图表**：五档/F10/快速交易全堆右侧 280px | `.mp-quote-area { width: 280px; flex-shrink: 0 }` | K 线主图可用宽度被吃掉 1/4~1/3，分屏对比时更窄 |
| R6 | **跨页传参靠全局变量 hack**：sessionStorage + `window.__prefillTrade` | `lib/trade.js` 注释直接承认「导致 Trade 组件不挂载、事件丢失」；useHotkeys F3/F4 写 sessionStorage | 跳转传参时序敏感、偶发失效 |
| R7 | **FunctionTree 高亮与 tab 失联**：只监听 `nav`，`switchTab` 不发事件 | FunctionTree 只 `addEventListener("nav")` | 点 tab 切换后左侧树高亮停留在旧页面 |

**为什么"新开浏览器"无法摆脱**：R1/R2/R3/R6 全部发生在**运行时交互路径**上，与 localStorage 无关——清空缓存、换新浏览器，只要"打开行情页 → 按 F3 / 切 tab 再切回"就复现。之前的多轮修复都在 R4（持久化净化）上打转，方向错了。

## 2. 改造目标（对标通达信 / 东财终端）

1. **多路切换**：任意页面可开 N 个实例（行情分析 ×3 各看各的票）；切换零销毁、零重连、零状态丢失。
2. **多行情兼容**：同屏多只票、多周期并存；tab 标题跟随代码；行情状态（五档/分时）互不串扰。
3. **多 tab 切换**：keep-alive 常驻 + LRU 上限 + Ctrl+1..9 / Ctrl+Tab / Ctrl+W 全键盘流；tab 栏溢出滚动、右键菜单、拖拽排序。
4. **自动分屏**：TDX 经典布局预设（1×1 / 1×2 / 2×1 / 2×2 / 1+2），一键应用；"自动分屏"开关下新行情自动进入当前 tab 的空位，满了自动开新 tab。
5. **去掉右侧固定栏**：图表全宽；五档/盘口/F10 下沉为行情页底部可折叠抽屉；快速交易改为浮层（保留快捷入口）。
6. **单条 WS 连接多路复用**：全应用唯一行情连接，引用计数订阅，非激活 tab 降频不拆连接。

│  │  t_01   │ │  t_02   │ │  t_03   │                           │

关键决定：**状态从「三层散落」收敛为「一个 store」**；**页面从「props 注入 + 挂载读 sessionStorage」改为「实例 params 受控」**；**WS 从「每页面一条」收敛为「全局一条」**。

## 4. 模块详细设计

### 4.1 WorkspaceStore —— 实例级 Tab 数据模型（新文件 `src/store/workspace.js`）

```js
// 数据模型（TypeScript 表意）
Tab      = { id: "t_<ts36><seq>",        // 实例唯一 id，跨会话不复用
             pageKey: "quote",            // 页面类型（仍来自 PAGES 注册表）
             params: { code, period, ... },// 实例参数（行情 tab 的股票代码等）
             pinned: false, title: null }  // title 为空时用 PAGES[pageKey].label + params 摘要

Layout   = { id, dir: "h"|"v", kids: [...] } | { id, pageKey, leafId }   // 沿用现有 Pane 树结构
State    = { version: 3, tabs: Tab[], activeId, layouts: { [tabId]: Layout }, aliveOrder: [] }
```

- **useReducer 单一状态源**，action 集中：`OPEN_TAB / CLOSE_TAB / CLOSE_OTHERS / CLOSE_RIGHT / ACTIVATE / MOVE_TAB / SET_PARAMS / SET_LAYOUT / APPLY_PRESET / PIN_TAB`。
- **持久化**：单 key `qmt_work.workspace.v3`，写入前 `validateState()`（schema 校验：tab id 唯一、pageKey 在 PAGES 内、layouts 树 sanitize 一次通过），**校验失败直接丢弃回默认**——从机制上杜绝"损坏数据递归渲染成空白"。写入用 300ms 防抖。
- **迁移**：首启动检测旧 `workbench.v1` + `panes.v2` → 合成 v3（每旧 tab 一个实例，params 空）→ 删除旧 key。迁移在 try/catch 中执行，失败即默认（仪表盘单 tab）。
- `aliveOrder` 记录激活时序，供 LRU 卸载用。

**根治点**：R4（三层持久化）、R1（实例模型）。

### 4.2 Workbench keep-alive 多路切换（重写 `Workbench.jsx`）

```jsx
<div className="wb-body">
  {aliveTabs.map((t) => (
    <div key={t.id}
         className="wb-tabpane"
         style={{ display: t.id === activeId ? "flex" : "none" }}
         aria-hidden={t.id !== activeId}>
      <TabView tab={t} active={t.id === activeId} />
    </div>
  ))}
</div>
```

- **所有 alive tab 常驻 DOM**：非激活 `display:none`，组件实例、内部 state、WS 订阅、ECharts 实例全部保留 → 切换零成本。
- **LRU 卸载上限**：`aliveOrder` 超过 `MAX_ALIVE`（默认 8，设置页可调 4–16）时，最久未激活的 tab 真正卸载（tab 条目保留，布局 params 均在 store，恢复即重建，体验损失仅一次重拉）。
- **TabView**：`<ErrorBoundary key={tab.id}><Pane layout={layouts[tab.id]} seed={tab} /></ErrorBoundary>`——error boundary 按实例隔离，某 tab 崩溃不影响其他 tab。
- **ECharts 尺寸修复**：`Chart.jsx` 增加 `ResizeObserver`；`display:none → flex` 时容器尺寸变化自动 `resize()`（当前切 tab 卸载重挂掩盖了此问题，keep-alive 后必须补）。

**根治点**：R2（切 tab 丢状态）。分屏树逻辑（`Pane.jsx` 的 split/close/sanitize）**保留复用**，仅将树 state 从「Pane 内部 + 自写 localStorage」改为「上提到 store，props 下发」。

### 4.3 nav 协议 v2（新文件 `src/lib/nav.js`，全站替换 dispatch 入口）

```js
navTo(pageKey, {
  params:  { code: "600519.SH", period: "1d" },  // 实例参数，取代 sessionStorage / window.__xxx
  openIn:  "auto" | "tab" | "replace" | "split-h" | "split-v" | "background",
})
// 兼容层：旧的 dispatchEvent(new CustomEvent("nav", {detail: "quote"})) 继续工作，
// 内部等价于 navTo("quote", {openIn: "auto"})。改造期内旧调用点零改动。
```

`openIn` 语义：

| openIn | 行为 |
|---|---|
| `auto`（默认） | 智能路由：目标页面已有激活实例 → `replace`（回写 params）；行情类且开了自动分屏 → `split`；否则新开 tab |
| `tab` | 总是开新实例 tab 并激活 |
| `replace` | 更新当前激活实例的 params（解决 F3/F4「点了没反应」） |
| `split-h` / `split-v` | 在当前 tab 的布局树中拆分出新 leaf 塞入新实例 |
| `background` | 开新 tab 但不激活（列表页中键行为） |

改造调用点（P0 全量替换，消灭 R6 的全局变量 hack）：
- `useHotkeys.js` F3/F4：`navTo("quote", { params: { code } })`；
- `lib/trade.js quickTradeNavigate`：`params: { code, price, direction }`，删除 `window.__prefillTrade`；
- `FunctionTree / MenuBar / CommandPalette / QuoteBoard 双击行 / LimitUp 点交易`：带各自 params。

### 4.4 MarketData 行情页：实例 params 受控（改造 `MarketData.jsx`）

```js
// props 接收 tab 实例（由 TabView 注入）：
export default function MarketData({ tab, active }) {
  const { params } = tab;                 // { code, period, adj, ... }
  const setParams = useSetTabParams();    // 内部 setCode/setPeriod 时回写 SET_PARAMS
  // code 变化：① 更新 store → ② tab 标题自动变「行情 · 600519」→ ③ 持久化天然包含
}
```

- `code/period/adj/count/指标` 全部收进实例 params（seed 默认值），**删除 sessionStorage 读写**。
- 行情 tab 标题 = `行情分析 · 600519 贵州茅台`（名称来自 hub 缓存），多实例一眼可辨。
- `active === false` 时：`klineQ` 照常（React Query 式缓存已在 hook 内）；tick 渲染降频（详见 4.5）。

### 4.5 QuoteHub —— 单连接多路复用（新文件 `src/lib/quoteHub.js` + `hooks/useQuotes.js`）

```js
// 全局唯一 WS（/api/v1/ws），挂载在 App 层 Provider
subscribe(codes: string[]) → unsubscribe()      // 引用计数：+1 重复订阅去重，-1 归零退订
snapshot(code) → Quote | null                   // 内部 Map 缓存，新订阅者即拿即用（替代 quotes_replay 等待）
useQuotes(codes) → { quotes: Map, state }       // 任何页面即插即用

// 激活感知（keep-alive 配套）：
// - 页面 active=false：退订实时推送，保留快照（切回时先渲染快照再续订，无闪白）
// - document.visibilityState=hidden：全局降频（仅维持心跳）
// - 重连：保留原指数退避（0.5s×2^n 上限 15s，MAX 10 次），重连成功后按现存订阅表整体恢复
```

接入方（P2）：MarketData（删除自建 WS）、TabBar 迷你行情、QuoteBoard、LimitUp、Ticker。后端 `/api/v1/ws` 广播协议不变（`subscribe {codes}`），**后端零改动**。

**根治点**：R3（连接风暴）。

### 4.6 TabBar UI 改造（重写 Workbench 的 tab 栏部分）

- **溢出滚动**：tab 多于容器宽时横向滚轮滚动（`overflow-x: auto` + wheel 事件转 translateX），两端渐隐提示。
- **右键菜单**：关闭 / 关闭其他 / 关闭右侧 / 复制 tab（同 params 新实例）/ 固定 pin / 在右侧分屏打开。
- **拖拽排序**（HTML5 DnD）：拖动 tab 调整顺序 → `MOVE_TAB`。
- **中键关闭**、**双击重置布局**（保留现有 ⟲ 功能移入右键菜单）。
- **迷你行情**：行情类 tab 显示 `最新价 涨跌幅%`（红涨绿跌），数据来自 QuoteHub 的 tab params.code；非行情 tab 只显示 label。
- **快捷键**（useHotkeys 扩展，仅非输入态生效）：`Ctrl+1..9` 直达第 N tab、`Ctrl+Tab`/`Ctrl+Shift+Tab` 循环、`Ctrl+W` 关闭当前、`Ctrl+T` 新建（命令面板风格）、`Alt+←/→` 历史回退（P3，store 记录 activeId 栈）。
- **FunctionTree 高亮修复**：高亮改为订阅 store 的 `activeTab.pageKey`（R7 根治）。

### 4.8 自动分屏与布局预设

**分屏预设（TabBar 右侧「布局」下拉，一键 `APPLY_PRESET`）：**

| 预设 | 结构 | 典型用法 |
|---|---|---|
| 1×1 | 单 leaf | 默认 |
| 1×2（左右）/ 2×1（上下） | 双 leaf | 两只票对比 / 日线+分时 |
| 2×2 | 四宫格 | 四只票自选盯盘 |
| 1+2 | 左大右二 | 主看 + 两只辅看 |

应用预设 = 把当前 tab 内现有 leaves（按激活顺序）重排进模板，空位补 `pageKey` 由用户当前上下文决定（行情 tab 默认补新行情实例，沿用上个 leaf 的 params 换代码）。

**自动分屏开关**（行情页工具栏 + 设置页全局默认）：
- 开启后 `navTo(行情类, {openIn: "auto"})` 的智能路由变为：当前 tab leaves < 预设上限 → `split-v` 进空位；等于上限 → 新开 tab（`openIn: "tab"`）。
- 关闭时维持"单实例 replace"行为（保守用户零打扰）。

**多股同屏对比增强（P3 可选）**：同 tab 内多个行情 leaf 支持「联动十字光标 / 独立」开关，同步周期与复权（默认联动，可单独解绑）。

### 4.9 状态流转全景（一次「F3 切上证指数」的新路径）

```
按 F3
 → navTo("quote", { params: { code: "000001.SH" } })
 → store: 当前激活 tab 是行情实例？ → SET_PARAMS（tab 标题立刻变「行情分析 · 000001 上证指数」）
 → MarketData props.params.code 变化 → useKline deps 变化 → 重拉（缓存命中则瞬时）
 → QuoteHub: 旧 code refcount-1 退订，新 code +1 订阅
 全程：无组件卸载、无 WS 断连、无 sessionStorage、无全局变量。
```

## 6. 分阶段实施计划（每阶段独立可验收、可交付）

### P0 —— 核心模型重构（根治切换失效与状态丢失）
| 项 | 内容 |
|---|---|
| 新增 | `store/workspace.js`（reducer + v3 持久化 + 迁移 + 校验）、`lib/nav.js`（navTo + 兼容层） |

## 7. 风险与兼容清单

| 风险 | 缓解 |
|---|---|
| keep-alive 常驻 N 页面内存上涨 | MAX_ALIVE LRU（默认 8）；设置页可调；非激活页退订实时推送 |
| ECharts 在 `display:none` 下尺寸为 0 | ResizeObserver + 切回 active 时主动 resize；Chart 组件单测覆盖 |
| 旧用户 localStorage 迁移 | try/catch 一次性迁移 v1+v2→v3，失败回默认；迁移后删旧 key |
| `nav` 旧调用点漏改 | 兼容层：string detail 继续工作（映射 auto）；Grep 全量扫描 `dispatchEvent.*nav` 清单化替换 |
| 后端 WS 协议 | 零改动（subscribe codes 广播协议不变） |
| CSS 缺类导致"界面无法加载" | 新增 className 全部同步补 `styles.css`；跑既有 className 差集防回归脚本 + Playwright 逐页 console/pageerror 捕获 |
| electron 壳 / 打包 | 纯前端改动，不涉后端与 EXE，无需重打包后端；`cd frontend && npm run build` 即生效 |
| 测试 | 逐文件 pytest 约定不涉前端；前端走 Playwright 脚本（现有 tests/*.mjs 扩展） |

## 8. 验证清单（最终交付门禁）

1. **多路切换**：开 3 个行情实例（600519 / 000001 / 300750），逐一切换，代码/周期/指标/WS 状态各自独立且不丢。
2. **多行情兼容**：2×2 分屏 4 只票 + 同屏 2 tab 6 只票，tab 标题、迷你行情、五档互不串扰。
3. **F3/F4/跨页跳转**：任意状态下按键，1 帧内完成代码切换（含已开/未开行情 tab 两种前提）。
4. **keep-alive**：tab 往返 10 次，DevTools Network 无重复 K 线请求、无 WS 重建。
5. **LRU**：开 10 tab，第 3 个被卸载者重新激活，状态从 store 恢复（params/布局不丢，数据单次重拉）。
6. **持久化**：刷新页面 tab 集合/激活/params/分屏布局全量还原；手工往 `workspace.v3` 写损坏 JSON → 回默认不白屏。

8. **自动分屏**：开关开启，从报价牌连续点 3 只票 → 1+2 布局自动填满，第 4 只自动新开 tab。
9. **回归**：Playwright 逐页 nav 无 console error / pageerror；className 差集为零；`npm run build` 通过。
