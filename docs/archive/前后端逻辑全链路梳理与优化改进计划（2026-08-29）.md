## 五、优化改进计划（四批次）

### 批次 A：热修（正确性 / 内存安全，建议立即做）

**A1（=R1）TTL 缓存加上限与淘汰** — `market.py`
- `_ttl_set` 改为：写入前若 `len(_TTL_CACHE) >= 512`，先清理全部过期键；仍超限则按「最旧写入时间」淘汰至 480。
- 实现用现有结构即可（`(ts, val)` 元组已带时间戳，无需引入 OrderedDict）。
- 验收：构造 600 个不同 key 写入后，`len(_TTL_CACHE) <= 512`；既有 ttl 命中行为不变。

**A2（=R2）Boards 深链 effect 去副作用化** — `Boards.jsx`
- 把 `setInterval` 回调改为在 updater 外比对：用 `useRef` 保存最新 rows（或把匹配逻辑移入 `loadBoards().then` 之后的普通回调），命中后直接 `selectBoard(...)`，`setRows` 仅用于渲染。
- 验收：`npm run lint` 0 告警；深链进入 boards 页（带 params.code/name）网络面板无重复 constituents 请求；StrictMode 下同样单次。

**A3（=R3）/market/quotes 补齐并发保护** — `market.py`
- 新增 `_QUOTES_FILL_SEM = asyncio.Semaphore(8)`，`_fill` 内 `async with` 包裹 `wait_for(get_quote(...))`。
- 验收：报价牌 200 只缓存全 miss 时，TDX 侧并发不超 8；响应时间与现在同量级。

**A4（=R5）sort_by 白名单校验** — `market.py` boards 端点
