# 标的检索与分析体系（2026-08-31）

> 目标：用户输入任意「代码 / 中文名 / 拼音首字母 / 板块名」，系统在**一次交互内**完成
> 检索定位 → 标的画像 → 多维分析 → 交易动作，链路零断点、缺数据显式标注、绝不伪造。

## 1. 现状与缺口

| 环节 | 现状 | 缺口 |
| --- | --- | --- |
| 检索 | `/market/search` 基于本地名称表索引，代码+中文名前缀/包含匹配 | 结果仅 `{code,name}` 无类型；不支持拼音首字母（TDX 习惯 `gzmt`→贵州茅台）；不搜板块；无键盘导航与历史 |
| 解析 | 无 | 用户输入 `513090` / `sh513090` / `香港证券` 无统一归一入口，各页面自行处理 |
| 画像 | `/market/stock-info` 给名称/板块/行业/概念 | 无标的类型判定（ETF/股票/指数/板块/债券），前端无法按类型差异化展示 |
| 分析 | MarketData 页自行拼 6-7 个接口（quote/kline/stock-info/financial/moneyflow/capital） | 无聚合端点；近期表现（5/20/60 日涨跌幅、52 周分位）完全缺失；估值/资金流/换手分散各处 |

## 2. 体系总览（三层链路）

```
用户输入（代码 / 名称 / 拼音 / 板块名）
   │
   ▼
① 检索层  GET /market/search            富搜索：{code,name,type,exchange,board,match} + 拼音 + 板块联合
          GET /market/resolve           归一解析：任意输入 → 标准QMT代码 + 候选列表 + 画像
   │
   ▼
② 画像层  classify_instrument()         标的类型判定（股票/ETF/指数/板块/债券/未知）
          （instrument.py，纯函数零网络）
   │
   ▼
③ 分析层  GET /market/analysis          多维聚合：快照/画像/表现/资金流/估值 并发拉取独立容错
   │        performance                 5/20/60日涨跌幅、52周高低、现价分位（真实K线计算）
   │        moneyflow                   净流入/内外盘/量比
   │        valuation                   PE/PB/市值（需券商，缺失标注 unavailable）
   ▼
交易动作   GET /trade/precheck → POST /trade/order（风控 + 幂等）
```

**核心原则**（延续项目既定规范）：
- 每个维度独立超时与容错，缺数据的维度返回 `null` + `availability` 标注，前端显示「—」；
- 类型判定基于「代码段 × 交易所后缀」双因子（`000001.SH` 是上证指数、`000001.SZ` 是平安银行）；
- 拼音首字母用 GBK 区间法（纯 stdlib，无第三方依赖）。

## 3. ① 检索层设计

### 3.1 `/market/search`（增强，向后兼容）

```
GET /market/search?q=香港&limit=12&include_boards=1
```

返回（每条新增 `type / exchange / board / match`，旧字段不变）：

```json
[
  {"code": "513090.SH", "name": "易方达香港证券ETF", "type": "etf",
   "exchange": "上交所", "board": "沪市", "match": "name"},
  {"code": "881305.SH", "name": "香港证券", "type": "board",
   "exchange": "板块", "board": "行业板块", "match": "name"}
]
```

- `match ∈ {code, name, pinyin, exact}`：命中的匹配方式（前端可高亮）。
- 拼音首字母：名称表构建时预生成（`pinyin_initials("贵州茅台") = "gzmt"`），搜索时 `q` 为纯字母则走拼音索引。
- `include_boards=1`（默认）：联合 `search_boards()`，板块结果排在股票之后、按相关度混排。
- 板块条目 `type=board`，前端选中后跳转「市场结构 → 板块行情」而非行情页。

### 3.2 `/market/resolve`（新增）

```
GET /market/resolve?q=513090
```

```json
{"q": "513090", "resolved": true, "code": "513090.SH", "name": "易方达香港证券ETF",
 "type": "etf", "exchange": "上交所", "board": "沪市", "match": "code",
 "candidates": [ ...同 search 富结构，最多 8 条 ] }
```

- 归一规则：纯数字 / `sh513090` / `513090.SH` → 按交易所后缀与代码段推断完整代码；
  唯一命中即 `resolved=true`；多候选给 `candidates` 由前端让用户选择；
  中文/拼音输入退化为 search 语义。
- 用途：命令面板、F3 快捷输入、外部深链、AI 工具调用（MCP 自描述）的统一入口。

## 4. ② 画像层设计（instrument.py）

`classify_instrument(code, name)` 纯函数，返回 `{type, exchange, board, label}`：

| type | 判定规则 | 例 |
| --- | --- | --- |
| `index` | `000xxx.SH` / `399xxx.SZ` / `899xxx.BJ` / `880xxx/881xxx.SH` | 000001.SH 上证指数 |
| `etf` | `51x/56x/58x.SH`、`15x/16x.SZ` | 513090.SH、159915.SZ |
| `stock` | 60/68/00/30 沪深 + 8/4 北交所（结合 classify_board 细分主板/科创/创业/北交） | 600519.SH |
| `bond` | `11xxxx.SH` / `12xxxx.SZ` 可转债 | 113xxx.SH |
| `board` | 880/881 前缀板块指数（名称含「概念/行业」亦可佐证） | 881305.SH |

> 注意双因子判定的必要性：`000` 开头必须结合交易所后缀才能区分指数（沪）与股票（深）。

## 5. ③ 分析层设计（/market/analysis）

```
GET /market/analysis?code=513090.SH
```

并发聚合 6 个维度（每维独立 `asyncio.wait_for` 超时 + try/except，失败不拖垮整体）：

| 维度 | 数据来源 | 关键字段 |
| --- | --- | --- |
| `snapshot` 实时快照 | `get_quote` | last / change_pct / volume / amount / bid / ask / 量额 |
| `profile` 标的画像 | `get_instrument_detail` | name / exchange / board / industry / concepts / 涨跌停 / 昨收 |
| `capital` 股本与限制 | `get_share_capital` + `get_price_limits` | 流通股本（换手率真实口径）/ 涨跌停价 |
| `performance` 近期表现 | 日线 K 线（本地缓存优先） | `chg_5d / chg_20d / chg_60d / high_52w / low_52w / pct_in_52w`（现价在 52 周区间分位） |
| `moneyflow` 资金流 | `get_moneyflow` | net / inside / outside / volume_ratio |
| `valuation` 估值 | 券商 `get_financial` | PE / PB / 总市值（无券商连接时 unavailable） |

返回骨架：

```json
{
  "code": "513090.SH", "name": "…", "type": "etf", "exchange": "上交所", "board": "沪市",
  "ts": "2026-08-31T16:30:00",
  "snapshot": {...} | null,
  "profile":  {...} | null,
  "capital":  {...} | null,
  "performance": {"chg_5d": 1.2, "chg_20d": -3.4, "chg_60d": 8.9,
                   "high_52w": 2.05, "low_52w": 1.55, "pct_in_52w": 72.0} | null,
  "moneyflow": {...} | null,
  "valuation": {...} | null,
  "availability": {"snapshot": "ok", "valuation": "unavailable", ...}
}
```

**近期表现算法**：取最近 250 根日线收盘价；`chg_Nd = close[-1]/close[-1-N] - 1`；
52 周高低 = 近 250 根 high/low 极值；`pct_in_52w = (last - low) / (high - low) × 100`。
K 线不足 N 根时该字段为 `null`（不外推、不伪造）。

## 6. 前端交互设计

### 6.1 GlobalSearch（顶栏检索）

- 结果条目左侧显示**类型徽章**（`ETF` 蓝 / `股` 灰 / `指` 紫 / `板块` 橙 / `债` 青），右侧交易所；
- **键盘导航**：↑↓ 在结果间移动、Enter 打开高亮项、Esc 关闭；
- **搜索历史**：localStorage 保存最近 8 条，无输入聚焦时展示历史（点击回填）；
- 板块结果（`type=board`）→ `navTo("mktstructure", {params:{tab:"boards"}, ...})`；
  股票/ETF/指数 → `navToQuote(code)`（现状保持）。

### 6.2 MarketData 画像条（行情页标题下新增一行）

```
[ETF] 易方达香港证券ETF · 上交所 · 沪市  |  5日 +1.2%  20日 -3.4%  60日 +8.9%
52周分位 72%  |  换手 1.8%  |  主力净流入 +2300万  |  数据源: 券商
```

- 数据源：`/market/analysis`（单请求，30s TTL 缓存）；
- 任一维度缺失显示「—」；估值维度无券商时显示「估值需券商连接」。

## 8. 边界与不做的事

- 不做港股/美股检索（当前名称表仅覆盖沪深京 + ETF；跨市场检索待数据源支持后扩展）；
- 不在搜索里做联网模糊纠错（保持零网络、毫秒级响应）；
- valuation 仅在券商连接时可得，不做估算替代；
- 不新建顶层页面：分析能力全部内嵌于现有「行情分析」页与搜索交互，避免入口再膨胀。
