# v0.4.5（R22）：TDX 传输层切换 easy_tdx（MIT）+ 数据链路诚实化

## 背景

eltdx 库采用「ELTDX Research-Only License」（禁止商用），是发布链路上的**阻断级合规风险**
（见 `docs/THIRD_PARTY_LICENSES.md` 3.2）。本版将 TDX 传输层切换为 **easy_tdx**
（MIT，净室实现，商用安全），eltdx 降级为「easy_tdx 缺失时的可选回退」，
且**不再随安装包分发**。

## 已知降级（诚实声明）

- **五档档位**：easy_tdx MAC 协议无档位命令（标准协议五档对当前服务端返回空），
  盘口面板显示明确提示；连接券商后恢复完整五档
- **minutes.aux**（分钟级买卖力道/量比对比序列）：easy_tdx 不提供 → `strength=[]`（量比改由快照真实值提供）
- **北交所行情**：easy_tdx MAC 返回空 → 明确报错，不伪造
- **ETF 清单首拉**：约 10 分钟后台清扫（每机器一次），就绪前返回空列表
