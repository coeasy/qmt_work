### 轮 2：死循环 / 生命周期

| 问题 | 修复 |
|------|------|
| **存量 e2e 测试失败** `test_flow9_alerts_and_webhooks`（干净 HEAD 上即失败——基线"1700 全绿"只是 collect 数，掩盖了执行失败） | 根因：alert_engine 用三参标准形态发事件，测试 harness 假回调只支持单 dict 形态 → 事件被 `emit_event` 兜底吞掉。harness 回调改为镜像 `WSManager.broadcast` 的**双形态兼容** |
| 3 处**悬空 `create_task`**（`phase_replay` 算法单续作 / `alert_engine` 通知派发 / `sync` 快照回填）：任务可能被 GC 中途回收、异常无人收割 | 新增 `core/emit.py::spawn_background()`——fire-and-forget 唯一安全实现（强引用防 GC + done 回调收割异常），`emit_event` 内部同步加固，全仓一处修全 |

### 轮 3：参数级契约 + 门禁覆盖

| 问题 | 修复 |
