# v0.4.7（R24）· 数据完整性专项：把「空着」变成「真的拿到」

> 发布日期：2026-10-04 ｜ 上一版本：v0.4.6
> 主题：**接口数据从"能通"到"全"**——新增字段级空值率审计脚本，量化出 15 族接口里 14 处恒空/部分缺失，逐项定位根因并修复。核心是三个**静默降级**缺陷：平台最常用代码形态直接被拒、深市股票被当成沪市查询、以及一次网络抖动就会永久污染缓存。

## 核心变更

| # | 变更 | 说明 |
|---|------|------|
| 1 | **代码形态统一（P0 断链）** | `_pfx6` 此前只认 `'sh600519'`，传入 QMT 标准形态 `'600519.SH'` 直接抛「非法 TDX 代码」——而 `stock_topics`/`stock_score` 恰恰吞掉异常返回空，于是**行业与题材对平台最常见入参形态静默恒空**。现支持三种形态（TDX 原生 / QMT `.SH` `.SZ` `.BJ` / 纯 6 位数字），并修掉一个更隐蔽的 bug：`'000001.SZ'` 被截成 `'000001'` 后再按代码段推断成 `sh`，**后缀这个权威市场标识被直接丢弃**。新增 `_MARKET_BY_NUM` 纯数字推断表（`60/68/90/51/56/58→sh`、`01/02/03/30/39/15/16→sz`、`43/83/87/92/89→bj`）；`'000001'` 裸代码天然歧义（上证指数 SH / 平安银行 SZ），按通达信自身约定取 `sh` 并写入测试固化 |
| 2 | **深市行业恒空根因（P0 数据错）** | `eltdx_source` 调用 F10/题材接口时传的是**裸 6 位代码**（`_num()`），门面对无前缀代码一律补 `'sh'` → 所有深市 `000xxx`/`300xxx` 与科创板 `688xxx` 被当成沪市查询。实测 `300750.SZ`（宁德时代）行业恒空，而真实数据是「电池/锂电池」；`688981.SH` 同理应为「半导体」。改为 `_to_eltdx()` 保留交易所 |
| 3 | **空结果不再永久污染缓存（P0 自愈）** | 行业/题材空结果此前无条件落盘并永久命中 → 一次网络抖动或接口临时缺口，重启后照样读到假空。新增 `_INDUSTRY_RETRY_TTL`（6h）：空值只留内存、可重试，**绝不落盘**；非空结果照常永久命中（行业极少变动）。实测本地缓存 21 条中 **10 条（近半数）是陈旧假空**，已清理为 12 条有效记录 |
| 4 | **MAC 快照字段补齐（P0 能力缺失）** | MAC 快照实测返回 **33 字段**，门面此前只暴露 11 个——`pe_ttm`、`pb`、`总市值`、`流通市值`、`换手率`、`量比`、`振幅`、`均价`、`主力净流入` 全被丢弃。补齐后 `stock-info` 面板的估值/市值/交易统计在**离线单机也能显示**，不再依赖外部行情源二次补齐 |
| 5 | **字段映射单点定义（杜绝漂移）** | `get_quote` 与 `get_instrument_detail` 此前各写一份字段映射，二者**必然漂移**（实测：界面正常但 stock-info 面板全空，就是 `instrument_detail` 按契约名 `getattr` 拿到 `None`）。抽成类属性 `_SNAP_METRIC_MAP`（契约名 → 传输字段名），两路共用；新增 AST 级守卫测试强制两方法都引用它 |
| 6 | **`limit_status` 真值推导** | 涨跌停状态此前恒空。现由 MAC 快照的 `buy_price_limit`/`sell_price_limit` 真值推导：`limit_up` / `limit_down` / `normal` / `unknown`（停牌无成交时诚实置 unknown，不猜） |
| 7 | **`trade_date` 恒空修复** | `daily_shares` 与 `daily_price_limits` 的 `trade_date` 恒空。新增 `_last_trade_date()`：以**上证综指最后交易日**为权威交易日历（`sh000001`，6h TTL 缓存），填入两个接口的数据日期 |
| 8 | **`main_net_amount` 孤儿字段收口（前端）** | 后端早就在返回「主力净流入（元）」，但前端资金流面板**从未展示**——是典型孤儿字段。现加入一行条第 5 项，并把口径说明写进 tooltip：它与「净流入 = 外盘−内盘」是**两套独立口径**（交易所大单口径 vs 逐笔委托方向推导），可能同号也可能异号，取不到显示「—」，**绝不用 net 折算冒充** |
| 9 | **市值/换手率口径统一** | 分析层此前一律用 `shares × price` 推导市值与换手率，与 stock-info 面板显示的快照原生值**对不上**（两个页面两个市值）。现优先取行情源原生值，推导值仅作兜底 |
| 10 | **新增数据完整性审计脚本** | `backend/scripts/audit_data_completeness.py`：对 15 族接口逐字段统计非空率，输出 `FAIL / 未知恒空 / 部分缺失 / 已知协议限制` 四类计数并区分「真缺陷」与「诚实降级」。脚本自身也修了一个假阴性：`_unwrap` 不识别 `topics` 属性，导致 11/15 族被误判为 0 行 |
| 11 | **新增 26 个回归测试** | `tests/test_tdx_data_completeness.py`：代码形态参数化（12 种形态 + 6 种非法）、映射单点守卫（AST 级）、空结果 retry 窗口（TTL 内命中 / 超窗重拉 / 非空免疫 / 不落盘 / 陈旧假空自愈） |

## 已知协议限制（诚实降级，非缺陷）

| 类别 | 说明 |
|---|---|
| `free_float_shares` | MAC 快照无自由流通股本，仅总股本/流通股本；选股用流通股本兜底 |
| `buy_levels` / `sell_levels` / `sum_buy_vol` / `sum_sell_vol` | easy_tdx 走 MAC 快照接口，协议本身不提供五档盘口 |
| `inside_dish` / `outer_disc` | MAC 批量快照无内外盘（仅单标的 `symbol_info` 富化路径可取） |

## 升级说明

- **无破坏性变更**：全部为字段新增/填充与内部修复，源 ID、端点、事件契约、REST 响应结构均未变。
- `stock-info` 面板的估值/市值/换手率/量比/振幅/均价在单机离线（仅 easy_tdx）环境下**首次可用**。
- 历史行业缓存中若有陈旧空值会被自动重试修复（无需手动清理）；如需立即生效可删除 `backend/data/stock_industry.json`。
