## 二、修复的真缺陷（3 处）

### 缺陷 1 ★ 指数名称永远显示代码（`000300.SH → "000300.SH"`）

**两处根因缺一不可：**

- `eltdx_utils.lookup_name`（**声明的唯一入口**）**从不查指数兜底表** `_INDEX_FALLBACK_NAMES`（含
  上证指数/沪深300/…）。其它源自己用，没经过这个统一函数 ⇒ 「能力存在但没人调用」。
- `registry._merge_quote` 结尾用 `name or code` **拿代码冒充名称**；
  `_from_broker` **没有**「详情名 == 代码」守卫（`_from_plugin` 有，注释解释了原因）⇒ 连着券商时
  详情层把指数名回落成代码，覆盖掉源层真名。

**修法**：
- `lookup_name` 接上指数兜底表（`SH/SZ` 后缀识别 + 名称兜底表查找）
- `_merge_quote` 把「名 == 代码」视为「无名称」，逐级回退：源层名 → 本地/指数表 → `""`
- `/market/quotes` **优先读** `SyncEngine.latest_quotes` 快照缓存，但**不经过** `_merge_quote`
  ⇒ 加 `_fill_missing_names()` **单一出口**补名

**回归用例** `tests/test_index_name_fallback.py`：22 例，覆盖：
指数代码识别 / 名称兜底 / `_merge_quote` 不冒充 / `_fill_missing_names` 单一出口。

### 缺陷 2 ★ 前端 12 处 `name ?? code` 在「返回 `""` 后」会渲染空白

`??` 对空串不生效。后端改「无数据」的表示形式（`None → ""`）后，前端 12 处会**变成空白**而不是
「回退到代码」。全改 `||`：

| 文件 | 用途 |
| --- | --- |
| `shell/DataPanel.tsx` | 数据面板抬头 |
| `shell/KLineChart.tsx` | K 线标题 |
| `domains/trading/OrderForm.tsx` (×2) | 下单标题/快捷 |
| `domains/algo/*`、`Conditions`、`Signals` | 算法/条件/信号卡 |
| `domains/market/QuoteBoard.tsx` (×2) | 报价牌/自选股 |
| `domains/trade/Trade.tsx` | 交易页抬头 |
| `domains/positions/Positions.tsx` (×2) | 持仓页 |

**教训**：改「无数据」表示前，先全站扫 `?? code/identifier` 的用法。

### 缺陷 3 ★ 限价单价格默认为空 → `Number("")||0` → 报单 `price=0`

下单页只 `disabled={busy}`，限价单价格框**空着直接点提交**会发 `price=0` 的限价单，
柜台会拒单或直接当市价单成交，**两种后果用户都毫无预期**。

**修法**：
- 行情到手**自动回填最新价**（`priceTouched` 保护用户输入）
- `priceMissing` 时**禁用提交**并给提示
- 判「价格可用」必须走唯一实现 `isLivePrice`（`shared/freshness`）——
  我第一版写的 `typeof p === "number" && p > 0` 被 `freshness.test.ts` 的源码扫描**当场挡住**（门禁有效）

## 五、界面布局评估（基于 35 页真浏览器截图）

**整体结论：布局合理**，核心原则：
- 左侧**自选股面板**跨页面**固定**（不动用户的关注列表）
- 顶部**菜单 + 面包屑**，中部**多页签**，右侧**实时指标/账号**
- 状态/健康信息**全在系统状态页**（不污染主流程）
- 空态**如实写明原因**（「当前无持仓 / 或账户未连接」）

**几个值得保留的好设计**：
- 仪表盘三栏：账户汇总 / 异常连接 / 系统健康，**信息密度适中**
- 设置页 3 列网格 + 每项「默认值 / 最小值 / 说明」——工程师视角清楚
- 自选股「单条移除（行内确认）+ 整体清空（模态）」**对称且合规**
- 离线场景的系统状态页：db OK / ws OK / brokers **UNAVAIL**（不混、不撒谎）
- 选股页底栏**诚实写**「未连接券商：选股依赖行情/本地板块数据，有 N 条数据可使用 0 只」

**潜在改进点**（**不阻塞本轮**）：
- 「分仓再平衡」**已无菜单项**（`menu:false`），入口在「多账户网格」页右上 ⇒ 探针误报为「无入口」（第 16 轮就加好了）

## 九、结论与下一步

1. **界面布局整体合理，无需重排**——只是局部一致性问题（自选股名）和细节打磨
2. **设置项整体合理，无需重排**——只有 `market.eod.enabled=false` 可讨论（用户改过则保留）
3. **不连 QMT 时行情 + 选股 + 研究完全可用**，只差「实时 tick + 真实下单」依赖券商
4. **三处真缺陷全部闭环**（指数名 / `??` 不生效 / 限价单 price=0）
5. **遗留**：自选股名称列在离线场景空（30 行修法已锁定）
6. **下一步**：自选股名称一致性 + 整体布局微调 + 是否将 `market.eod` 默认开
